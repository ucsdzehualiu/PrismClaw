# 天气查询技能

## 触发条件
用户提到"天气"、"气温"、"下雨"、"刮风"、"出门穿什么"等关键词时，必须使用此技能。

## 执行流程

### 步骤 1：确认城市
从用户消息中提取城市名。如果未指定，询问用户。

### 步骤 2：搜索天气
调用 `web_search` 工具，搜索词格式：
```
{city} 实时天气 温度
```

### 步骤 3：提取数据
从搜索结果中提取：
- 当前温度
- 天气状况（晴/阴/雨/多云）
- 湿度
- 风速

### 步骤 4：格式化回复
用表格呈现天气数据，并给出简短建议。

## 回复模板
```markdown
**{城市} 实时天气**

| 项目 | 数据 |
|------|------|
| 温度 | XX°C |
| 天气 | XX |
| 湿度 | XX% |
| 风速 | XX km/h |

**建议：** {一句话建议}
```

## 重要
- 若搜索结果为空或不完整，诚实告知用户搜索受限
- 不要编造天气数据
