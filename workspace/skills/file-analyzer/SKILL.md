# 文件分析技能

## 执行流程

### 步骤 1：确认文件路径
从用户消息中获取文件路径。如果未指定，询问用户。

### 步骤 2：读取文件
调用 `view_text_file` 读取文件内容。

### 步骤 3：分析内容
根据用户需求进行分析：
- 如果是代码：统计行数、函数数、类数
- 如果是数据（CSV/JSON）：统计记录数、字段列表
- 如果是文档：提取关键段落、统计字数

### 步骤 4：输出报告
```markdown
**文件分析：** `{filename}`

| 指标 | 数值 |
|------|------|
| 总行数 | XXX |
| ... | ... |

**主要内容：** {摘要}
```
