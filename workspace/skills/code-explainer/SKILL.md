# 代码解释技能

## 执行流程

### 步骤 1：获取代码
从用户消息或指定文件中获取代码。如果是文件路径，先调用 `view_text_file` 读取。

### 步骤 2：分析结构
逐项检查：
- 整体架构（模块划分、依赖关系）
- 关键函数/类的作用
- 数据流向
- 潜在问题（性能、安全、可读性）

### 步骤 3：输出解释
```markdown
**代码分析**

**整体结构：** {一句话概述}

**核心逻辑：**
1. {步骤1}
2. {步骤2}

**注意事项：** {关键提醒}
```
